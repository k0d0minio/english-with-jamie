# studios/read — things to read

Entered when Jamie asks for reading suggestions. Same rules as [`../watch/`](../watch/CONTEXT.md):
proposals, curated by Jamie. Work from the repo root.

## Inputs

| Layer | File | Why |
|---|---|---|
| 3 | [`../_shared/learner.md`](../_shared/learner.md) · [`../_shared/voice.md`](../_shared/voice.md) | Taste, level, tone |
| 3 | [`../_shared/formats.md`](../_shared/formats.md) § Read | File shape |
| 4 | `intake/*.md` | Subjects she likes; what Jamie wants her reading (Canadian press, short fiction, how-to) |
| 4 | `content/read/` — frontmatter only | Don't repeat |

## Process

1. **Three to five entries per run.** Articles under 1,500 words marked `short`; longer
   pieces and books marked honestly. Prefer living publications and stable URLs; if a URL
   can't be verified in session, leave `url` out and name the source.
2. **Say why** in two sentences, in the voice. One phrase or idiom to look for.
3. **Suitable for a minor.** No paywalled links without saying so.
4. **Save** as `content/read/<slug>.md` with `draft: true`.

## Output

`content/read/<slug>.md`, one per piece.

## Gate (Jamie's)

- [ ] Jamie opens each link, removes `draft: true` or deletes the file.

## Done when

Entries saved and listed back with source and length.
